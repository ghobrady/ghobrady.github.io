# Material provenance

binding-grain.webp was generated for this project using the built-in imagegen tool, then encoded as WebP without changing the material content. No third-party scan was used. The original PNG is retained in the local generation archive.

Generation prompt:

> Use case: photorealistic-natural. Asset type: neutral diffuse material map for a tactile personal bookshelf website. Generate one square flat scan of fine aged bookbinding material, mid-gray monochrome, edge-to-edge. Extremely fine irregular leather-like cellulose fibers and softly tangled shallow grain, delicate branching wrinkles and small natural pores, subtle low-frequency mottling. Soft, handled vintage hardcover finish, matte, not glossy, not distressed. Dense fine detail but restrained contrast around 50% gray. Flat evenly lit orthographic scan: no directional lighting, no shadows, no objects, no book shape, no borders, no text, no patches, no seams, no vignetting, no large cracks, no repeating straight grid, no watermark. Should serve as a neutral texture overlay tinted navy, cream, sage, terracotta, yellow, burgundy, blue and gray by CSS. 1024px square.

cool-fine-plaster.webp is the active wall material, generated using built-in imagegen with the approved cool fine plaster mockup as a material reference, then encoded as WebP without changing the material content. CSS repeats it at 512px square with 65% opacity over the existing wall lighting gradients. The live books, shelves, typography and cast shadows are rendered separately. The original PNG is retained in the local generation archive.

Generation prompt:

> Use case: photorealistic-natural. Asset type: seamless repeating wall material tile for an existing bookshelf website. Input image 1 is a MATERIAL STYLE REFERENCE only: match the cool fine plaster wall visible behind the books, not the books or shelves. Generate ONLY a square, edge-to-edge, evenly lit flat orthographic scan of that very pale cool gray painted fine plaster wall. Target average color approximately #e0e3e4, with delicate irregular fine sandy stipple, tiny shallow plaster pores and almost imperceptible trowel unevenness. Match the reference's quiet tactile matte finish. Low contrast and very subtle, clean and nearly white; no broad cloudy patches. Texture must tile seamlessly in both directions without visible seams, and have consistent detail density over the whole square. No vignette, no gradient lighting, no cast shadows, no objects, no books, no shelves, no text, no borders, no cracks, no stains, no watermark, no bricks, no concrete panels. 1024 by 1024 square.

wall-grain.svg is the original project-authored fractal-noise treatment, retained as an unused source material.
